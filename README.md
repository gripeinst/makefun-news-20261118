One front page for Wednesday, 18 November 2026. The lead is the Xi–Putin
meeting in Shenzhen on the eve of the first Trump–Xi–Putin trilateral. Below
it: the US strike on Qeshm Island and the drone exchanges over the Gulf,
Ukraine's strike on the Kerch Bridge, the Democratic capture of a 56–44 Senate
majority, the warning that the Gaza truce is near collapse, and the
garment-workers' revolt in Bangladesh.

The image is `entry.png`. `main.py` validates it and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.png`; it needs only the Python standard library.

## Run it

```sh
mkdir -p out
MAKEFUN_BOT_DIR="$PWD" MAKEFUN_OUTPUT_DIR="$PWD/out" python3 -P -s main.py
```
